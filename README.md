
# RISC-V Multicycle Control Unit

## Overview
This project implements a RISC-V Multicycle Control Unit using SystemVerilog. It uses a Finite State Machine (FSM) to manage instruction execution across multiple clock cycles, handle state transitions, and generate control signals required for processor operation.

## Features
- FSM-based control unit design
- Multicycle instruction execution control
- State transition logic
- Control signal generation
- SystemVerilog RTL implementation
- Readable state representation for easier debugging

## Technologies Used
- SystemVerilog
- RISC-V Architecture
- RTL Design
- Finite State Machine (FSM)
- Digital Logic Design

## Working Principle
The control unit operates as a Finite State Machine, transitioning between states according to the current state and instruction requirements. Each state generates the control signals required for the corresponding stage of instruction execution.

## Learning Objectives
- Understand FSM-based processor control
- Practice SystemVerilog coding
- Learn state encoding and transitions
- Explore multicycle processor architecture
- Develop RTL design skills
